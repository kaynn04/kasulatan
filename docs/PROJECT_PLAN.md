# Project Plan

## Project Name
Kasulatan

## Project Goal
A web app that helps people create clear digital transaction agreements, capture electronic consent, and store a stronger evidence trail for private transactions in the Philippines.

## Target Users
- People lending money
- People selling items informally
- People offering small services
- People who want a clearer record than Messenger chats

## Phase 1 Core Features
- User registration and login
- Create an agreement
- Invite the other party
- Review and sign agreement electronically
- Pay a service fee
- View receipt and agreement history

## Phase 1 Agreement Types
- Loan / Utang agreement
- Sale of Item agreement
- Service agreement

## Core Pages
- Landing page
- Register page
- Login page
- Dashboard
- Create agreement page
- Agreement details page
- Review/sign page
- Checkout page
- Receipt page

## Core Data Models
- User
- Agreement
- AgreementParty
- Payment
- AuditLog
- AgreementAttachment

## Product Reminder
This platform helps users record agreements and transaction evidence electronically.
It does not provide legal advice and does not guarantee the outcome of any legal dispute.
