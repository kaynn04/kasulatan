# Tech Stack

## Main Stack
- Next.js
- TypeScript
- Tailwind CSS
- Prisma
- PostgreSQL
- NextAuth or Auth.js
- Stripe
- Vercel

## 1. Next.js

What it is:
A full-stack React framework for building web applications.

Why we are using it:
- It lets us build frontend pages and backend logic in one project
- It is good for learning full-stack fundamentals
- It helps me understand how UI and server code connect
- It supports routing, forms, server actions, and API handling

What I should learn from it:
- file-based routing
- page structure
- server vs client code
- how frontend talks to backend
- how a full-stack app is organized

## 2. TypeScript

What it is:
JavaScript with types.

Why we are using it:
- It helps catch mistakes early
- It makes data shapes clearer
- It helps when connecting frontend, backend, and database code

What I should learn from it:
- object shapes
- function parameter types
- return types
- how types reduce integration mistakes

## 3. Tailwind CSS

What it is:
A utility-first CSS framework.

Why we are using it:
- It makes styling faster
- It is commonly used with Next.js
- It helps us focus first on structure and functionality

What I should learn from it:
- layout basics
- spacing
- typography
- responsive design

## 4. Prisma

What it is:
An ORM for working with the database using code.

Why we are using it:
- It makes database models easier to define
- It helps connect code to database tables clearly
- It is beginner-friendly for understanding backend-data relationships

What I should learn from it:
- schema design
- models and relationships
- migrations
- querying data from backend code

## 5. PostgreSQL

What it is:
A relational database.

Why we are using it:
- Our app has structured data with relationships
- Agreements, users, parties, payments, and logs fit relational data well
- It is widely used in production systems

What I should learn from it:
- tables
- rows
- primary keys
- foreign keys
- relationships

## 6. NextAuth or Auth.js

What it is:
A library for handling authentication.

Why we are using it:
- Users need accounts
- Some pages and actions should only be accessible to logged-in users
- Auth is a core part of real full-stack apps

What I should learn from it:
- login and registration flow
- sessions
- protected routes
- how backend identifies the current user

## 7. Stripe

What it is:
A payment platform.

Why we are using it:
- Users will pay us a service fee
- It is easier and safer than building payment handling ourselves
- It is widely used and well documented

What I should learn from it:
- checkout flow
- payment status
- redirect after payment
- backend verification of payment

## 8. Vercel

What it is:
A hosting platform.

Why we are using it:
- It works very well with Next.js
- It makes deployment simpler
- It helps us learn how apps go live

What I should learn from it:
- deployment flow
- environment variables
- production vs development environment

# Why This Stack Is Good For Learning Full Stack

This stack teaches the full chain:

- Next.js teaches app structure
- TypeScript teaches safer integration
- Tailwind teaches UI building
- Prisma teaches database-to-code mapping
- PostgreSQL teaches data storage
- Auth teaches user identity
- Stripe teaches external service integration
- Vercel teaches deployment

# Important Reminder

I am not just choosing tools.

I am choosing tools that help me understand:
- how data moves
- how features are built end to end
- how frontend, backend, and database connect
